3. Kasus Uji Diagnostik (TC01–TC05)

TC01 Positive Relawan Tambah Produk Thrift

POST /api/admin/produk • Target: 201 Created

TC02 Positive Admin Verifikasi Status Pesanan

PATCH /api/admin/pesanan/1/status • Target: 200 OK

TC03 Negative Auth Tamu Intip Pesanan Tanpa Token

GET /api/admin/pesanan (Tanpa Token) • Target: 401 Unauthorized

TC04 Negative RBAC Relawan Bypass Ubah Status Pesanan

PATCH /api/admin/pesanan/1/status (Token Relawan) • Target: 403 Forbidden

TC05 Limit Check Penyaluran Donasi Melebihi Saldo Kas

POST /api/admin/donasi/penyaluran (Nominal > Saldo) • Target: 400 Bad Request
